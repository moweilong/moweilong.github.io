# 统一应用日志中心

统一应用日志中心翻译为 `Unified Application Log Center`，涵盖 “集中收集、存储、查询、分析应用日志” 的核心职能，既贴合 IT 行业术语的严谨规范，亦契合技术场景下的表达习惯，其缩写形式为 `UALC`。
