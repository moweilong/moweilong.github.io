## 概述

在计算机内存昂贵，处理能力有限的美好旧时光里，用比较黑客范的位运算方式去处理信息是首选方式（某些情况下只能如此）。时至今日，直接使用位运算仍然是很多计算领域中不可或缺的部分，例如底层系统编程，图形处理，密码学等。

Go 编程语言支持以下按位运算符：

| **运算符** | **含义（中英文）**         |
| :--------- | :------------------------- |
| `&`        | 按位与（bitwise AND）      |
| `\|`        | 按位或（bitwise OR）       |
| `^`        | 按位异或（bitwise XOR）    |
| `&^`       | 按位与非（AND NOT）        |
| `<<`       | 左移（left shift）         |
| `>>`       | 右移（right shift）        |

本文的余下部分详述了每个操作符以及它们如何使用的案例。

## & 运算符

在 Go 中， `&` 运算符在两个整型操作数中执行按位 `AND` 操作。`AND` 操作具有以下属性:

```math
Given operands a, b
AND(a, b) = 1; only if a = b = 1
else = 0
```
